# 系统二 · 生产记录页面与交互规格

## 1. 首页与实际记录

侧栏使用已有「生产记录」。模块内提供「生产任务」和「实际记录」。默认打开生产任务，业务日期默认为当天，展示两个车间。首页固定提供「计划外生产」入口。实际记录中按车间和单日提供「核对当日记录」入口。

| 视图 | 默认和筛选 | 列表内容及动作 |
| --- | --- | --- |
| 生产任务 | 默认为今日计划，两车间均展示。可切计划日期范围、车间、订单、执行状态。需要按实际日找任务时使用单独的实际日期条件 | 按计划日期、车间和同日顺序展示任务。列出计划产品、关联订单、计划合格量、有效实际、本任务差额和当前提示。点击打开任务详情。来源 S2-R01 |
| 实际记录 | 默认看当天实际。可按实际日期、车间、订单、类型、任务或归集筛选，可筛「计划外生产」 | 每行显示记录类型、实际日期、录入时间、车间与产品、记录数量、适用订单、经办人及补录原因。详情查原始事实、更正记录和库存流水。来源 S2-R03、R04 |

计划日期和实际日期分别标注。今日计划不因补录的实际日期不同而换日。实际记录按真实业务日出现，历史任务详情仍可查到该笔实际。搜索或翻页使用服务端分页。任务或订单合并显示的汇总基于服务端结果。

## 2. 任务详情

任务详情以「计划摘要」和「实际记录」时间线为主。S2-R02 提供任务版本、车间、产品、已确认数量、计划日期、关联订单与任务份额、已录实际、待到料或待称重提示、预留和可操作项。S2-R03 分页加载该任务的事实，按实际业务日、实际时点和记录 ID 排序，录入时间单独展示。记录点击展开原始值、生效值、库存关联和更正历史。

| 位置 | 内容及操作 |
| --- | --- |
| 计划摘要 | 显示任务与计划编号、车间、规格、日期和同日顺序、计划合格量、已记录合格量及差额。显示本任务用料、已预留数量、预期到料与实际到料。可打开来源日计划和关联订单。 |
| 车间一动作 | 「登记投料」「铜杆称重」。 |
| 车间二动作 | 「登记交出」「铜丝称重」。对于尚未接收的交接，在原记录行显示「补录接收」。 |
| 执行与结束 | 提供「登记实际起止」「确认无合格产出」「结束日任务」。首次登记投料、交出或称重时，可在同一表单勾选同时登记实际开始。 |
| 订单操作 | 通过关联订单打开「订单生产结束」。多订单任务先选择目标订单，再展示与本单有关的真实结论和差额。 |

后端的可操作项提示用于控制按钮可用性及说明阻塞原因。每次写入仍以服务端最新的任务、订单、库存与归集版本校验。页面将任务的保留计划量与更正后的实际量分开显示。

## 3. 车间表单

实际业务日期默认当天，可改为实际日期。起止、交接时点以现场发生时间录入。经办人必填，数量用吨，最多三位小数，总金额用人民币元，最多两位小数。补录历史事实、重要更正、超差放行和不足量结束需要相应原因。

| 操作 | 输入及提示 | 保存后显示 |
| --- | --- | --- |
| 登记实际起止 S2-R05 | 实际日、已经发生的时间起点或终点、经办人、说明。有两端时核对先后。若首次实际事实已随附开始时间，时间线直接回显本次记录。 | 实际起止和执行进展。数量仍由投料、交接和称重分别登记。 |
| 登记投料 S2-R07 | 实际日、本次铜板投入量、实际材料总金额（可待补）、经办人。显示本任务原计划及适用库存，本次实测量由用户填写。 | 显示实际铜板投入及关联出库。金额缺失显示待核算，后续补金额走 S2-R08。 |
| 铜杆称重 S2-R09 | 本次新增合格 Φ8 铜杆重量、实际日、关联的实际投料依据或归集、经办人。多次称重可引用同一投入。 | 本次一次入库、任务累计量、供料兑现及剩余缺口。 |
| 登记交出 S2-R10 | 本次实际交出重量和时间、接收车间任务或实际归集、经办人。接收已发生时可同时填实收重量和时间。仅有实际交出时，接收保持空值。 | 原交接记录及一次铜杆出库，接收为空时显示待接收。 |
| 补录接收 S2-R11 | 从该交接记录回显原交出重量与时间，只填实际接收、实际时间、经办人和原因。前端可预览误差，服务端作最终判断。误差超过 5% 时，表单提供明确放行动作并要求原因。 | 更新同一交接的接收记录和状态，库存扣减结果查原出库流水。 |
| 铜丝称重 S2-R12 | 每次换单停机或当日末次停机，登记本次新增合格量。选一个规格、实际日、对应任务和每个订单的实际归属份额。同规格且现场确为合并称重时，按实际依据填写已知任务分量，未明确的任务份额显示待补。页面预览公共差额。成本来源区展示对应领杆交接及本次实际使用的交出数量份额，唯一明确来源可回填，多来源未明确则标待补。 | 以服务端返回的有效归属、公共差额及库存流水为准。同一批合格铜丝按规格入库一次。领杆来源未明仍能保存真实称重，成本待核算。 |

录入中若用户打开其他任务，前端丢弃旧请求对当前表单的回填，保留明确选中的任务和版本。日期、规格及归属冲突定位到具体字段。只保留实际已量得的数，金额可以待补。

## 4. 零产出、结束和更正

- **零产出 S2-R14**。选择确认范围为本任务或整个车间业务日，填写原因。任务无合格产出只影响该任务。确认整日零产出时检查同一车间当天计划内外的所有正产出。未经称重且未经零产出确认时显示「待统计」。
- **结束日任务 S2-R15**。录入真实停止时刻，显示该任务原计划、已记合格量和差额。未称重显示待补。若有不再需要的未用预留，显示将释放的范围并由服务端按已确认约束处理。之后的实际补录继续沿原任务。剩余需求另到「订单与计划」安排。
- **订单生产结束 S2-R16**。先查看该订单原需求、实际新产、既有有效成品分配、当前结论和差额。正常结束依据已齐的合格量。确实不再追加且仍有不足时，选「不足量结束」并填写原因。保留原要求、实际、差额和可交付成品。交付与确认约定金额从订单详情办理。
- **更正 S2-R06/R08/R11/R13**。从原记录进入，更正前事实与拟修改值并列显示，填写原因及经办人。金额补齐、接收补录和说明更正与实际数量差额分别反馈。误确认零产出时，从该记录撤销确认并留痕，再补录正产出。有下游库存或交付冲突时显示受影响的流水、归属或交付记录，原数据仍可查。

## 5. 计划外生产

从首页点击「计划外生产」。先确定实际日期、车间与产品。选定的车间与产品决定可登记内容。若查到对应已确认任务，页面提供原任务入口，跨日及历史登记都可走该任务。确无对应任务时继续补录真实事实，使用实际订单及规格校验有归属的记录。

1. 填写本次补录原因和经办人。第一笔事实可从实际起止、铜板投料、铜杆称重、领杆交接或铜丝称重中按车间选择。按同类表单输入真实量和日期。
2. 保存调用 S2-R17。成功打开对应归集下的实际时间线，回显「计划外生产」、关联订单与已过账流水。已有归集从实际记录进入，再用「补录同次生产」关联后续事实。跨日事实各填自己的实际日。
3. 补录接收和更正仍从原交接或事实记录进入。实际影响订单剩余加工范围时提示复核相关计划，计划调整从「订单与计划」办理。

## 6. 保存和异常回显

- 成功后刷新任务摘要、事实时间线及对应订单依据。回显本次记录 ID、实际量、库存动作和待核算项。
- 400 或 422 定位字段或所缺实际依据。409 保留全部输入，显示当前版本和受影响对象，由用户核对后更新依据。等待结果或网络中断时，用原内容及原请求 ID 重试。
- 同一事实在「实际记录」和任务详情共享同一 ID。用户可查看更正历史，统计按该笔事实当前的有效数量计算一次。
- 相关记录或部分数据不可用时显示读取失败或待补。余额、原计划和已确认事实保留各自的来源。

请求及响应见[接口开发规范](系统二-生产记录-接口开发规范.md)。页面、接口和数据库的联调场景见[开发任务与验收](系统二-生产记录-开发任务与验收.md)。

## 7. 按车间核对当日记录

从实际记录或统计日详情进入，固定一个实际日和车间。S2-R18 显示该日计划内外的投料、交接、称重和归属汇总、源修订、录全状态、最后确认及失效原因。支持定位具体原记录补齐。新日未经确认时显示尚未录全，已有确认按接口有效状态回显；过往日期也不自动视为录全。

「确认当日记录已录全」提交 S2-R19，带日状态版本与所核对的来源修订。用户确认范围为当天已经发生的生产。已发生但尚缺称重等影响产量分母的记录应先补齐；未执行的计划任务不自动生成实际。未来日期禁止确认。材料金额、能源、价格缺失或接收尚未发生时保留成本缺项，不要求填虚构资料。整日没有合格产出时先登记对应车间日零产出确认，再声明录全。

成功显示人员、时间及核算进度。后续仍允许补录和更正，保存后明确提示受影响的日确认已失效；修改实际日期时列出原日和新日。日确认冲突保留当前核对范围，重新读取明细后再确认。原样重试沿用同一请求 ID。核对结果只推进录全状态和核算依据，不改变实际称重、现场设备、库存数量或订单生产结束。
