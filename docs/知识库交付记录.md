## 本地复现

1. 按 README 配置独立开发 MySQL，运行 scripts/Start-Dev.ps1。不要将验证指向业务数据库。
2. 前端 npm test 与 npm run build；后端 mvn -gs ../scripts/maven-settings.xml -s ../scripts/maven-settings.xml verify。
3. 先运行 scripts/Prepare-KnowledgeVerification.ps1，准备专用演示设备 code=KNOWLEDGE-VERIFY、档案 typeCode=OTHER。脚本仅在本地独立开发库创建演示文章、附件和工单，保留这些记录供重启复核，不改真实维修事实。
4. 在项目根目录运行 node scripts/verify-knowledge.mjs。脚本覆盖筛选去重和分页、步骤顺序、清空字段/附件、并发版本、并发同请求重放、同请求异内容拒绝、共享手册、配图后版本保护、草稿/待验收/验收失败工单拒绝、已完成工单案例与来源保留、失败事务重试。
5. 停止并重启后端，运行 node scripts/verify-knowledge.mjs --read-after-restart。
6. 启动带 remote-debugging-port=9338 的测试 Chrome，运行 node scripts/ui-check-knowledge.mjs，验证知识页交互、安全文本、故障重试和旧页面导航。
