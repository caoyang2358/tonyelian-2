# 系统二 · 订单与计划排产计算设计

本文件将[需求基线](需求基线.md)第 5–7 节细化为第一版排产规则。S2-P01 用当前业务数据生成可编辑草稿，S2-P06 依据同一规则确认草稿并提交正式计划。

## 1. 输入与数量边界

| 输入 | 排产使用方式 |
| --- | --- |
| 订单 | 读取交期、规格、原需求、实际及既有有效归属、交付事实、人工优先级和版本。 |
| 生产范围 | 计算仍需供给的铜丝吨数，校验人工填写的用杆总需求对应这部分新加工范围。 |
| 实物与预留 | 分别读取三类物料实物及有效预留，按物料收集可用量。 |
| 未来供料 | 读取车间一已有有效日任务、未兑现的有效供料承诺及用料时点。 |
| 产能与任务 | 读取两个车间在计算窗口内的普通和特殊日产能、已确认任务及实际保护条件。 |

用于试算的中间数量统一按公斤整数或可精确换算的十进制处理，出参以吨的小数字符串表达。订单已交付的数量与尚未交付的有效归属一同抵扣原需求，每份成品只计一次。属于订单的新生产通过已形成的实际归属进入这个计算。生产显示值独立查询实际记录。

```text
待满足铜丝量 = max(0, 原需求量 − 已实际交付量 − 有效归属尚未交付量)
仍需新加工量 = max(0, 待满足铜丝量 − 本草稿拟分配的公共成品量)
本次可新增安排量上限 = max(0, 仍需新加工量 − 本次保留的有效任务尚待产出量)
净新增铜杆量 = max(0, 本次适用的计划用杆总需求 − 本次可用现货份额 − 有效预期供料份额)
铜板计划量 = 向上取整至 0.001 吨（同一确认用料范围的净新增铜杆量 × 1.05）
```

保留任务的覆盖量按该订单的有效待产份额计算，已通过成品归属或交付抵扣的实际产出只计一次。明确替换的未开始任务，其份额在同一次确认中随旧任务更新。有实际或已开始的任务按保护规则办理。

联合评估时，人工标记为优先的急单先参与试排，允许跨交期优先安排。同一优先级内按交期、录入时间、订单 ID 依次升序。车间二仍以每张订单自己的交期为倒排依据。订单列表默认按交期展示。已有预留只在明确替换的可重排范围内重新分配，其他有效预留继续占用。

## 2. 评估与试排

1. **读取一致的起点。** 核对所选订单、范围及版本，读取从当前业务日开始的日历。历史交期可提示逾期，排程日期从当前业务日起计算。将已开始或已有投入、领用及称重的任务标为保护项。
2. **先用成品。** 按规格、订单顺序在试算中分配自由公库份额，同一份成品只分一次。全量满足的订单形成分配草稿。部分匹配改变了剩余加工范围时，提示重核原用杆总需求，允许在同一草稿补齐。缺用杆依据时可以继续编辑待办方案。
3. **车间二倒排。** 对剩余加工量从交期与窗口截止日中的较早日期开始，按可用合格产出容量向前试排。特殊日期值先于普通值，停产日跳过。每一天扣除已生效且不替换的任务量和当前草稿已占的量。记录各日计划合格铜丝量、未排量及风险。
4. **把已确认的用杆总量分到用料任务。** 若同一已确认剩余加工范围拆为多日，自动建议按各日计划铜丝量比例分摊这份总量。先向下取整到公斤，再按小数余数从大到小补齐尾差，余数相同按用料日期、顺序、任务键排序。试排未覆盖整个范围时，计算时包含一份待安排的剩余用杆量，日任务与待安排份额合计等于总量。人工可在原草稿重核实际安排范围与用杆量，保留未排量与缺项。
5. **按用料时点匹配铜杆。** 优先利用本次可用现货，再匹配未另行承诺且能在用料时点前兑现的有效未来供料。同日要求明确源任务先于用料任务。试算中扣减已分配份额，按任务保留现货及未来供料来源，余额仍不足的部分形成补产缺口。
6. **车间一联合补排。** 纳入已知、未来且尚未开始的可重排净需求，按用料先后满足累计供料。在可用铜板、日期产能和已有保护任务的约束下，尽量集中安排，先尝试用料前可用日期。同日衔接带供料先后。铜板计算以本次确认用料范围的净新增铜杆合计为基数。拆分到任务时，在公斤单位分配已取整的总量并保持总量守恒。
7. **联合校验并输出。** 用实际库存边界、有效日产能、产出产品规格、各任务供料和同日顺序检查建议。有供料日期冲突时可在窗口内重新尝试车间二日期。如果第一版试排找不到可执行的安排，返回已有草稿和具体阻塞因素，由用户在原草稿调整。

比例分配只用于拆分同一加工范围已人工确认的用杆总量。新加工范围的用杆总需求由用户重新核定。人工改动后需要按当日任务重新检查供料。

## 3. 确认与重排检查

- 前端将草稿中的任务、订单份额、成品分配、物料及任务之间的供料关系、替换范围和版本一并提交。后端重新算可用库存、有效产能、有效需求、净新增和铜板量。
- 每个任务的计划产品、车间、顺序、数量和用料份额都须可追溯。建议任务取得所属车间和日期尚未使用的顺序号，保留既有任务顺序。供料关系单独表达跨车间先后。车间一合并任务的订单份额只表达需求归属，其总产量按任务计一次。
- 按用料时点逐笔核对供料，确保没有一份现货或未来产出被重复使用，已知短缺与未确认依据不能作为正常可执行方案生效。可独立确认成品分配，也可先确认订单中能够执行的部分生产任务。只为已确认任务建立对应预留和供料承诺，余量待安排。后续补排按有效任务和实际重新计算。
- 可执行方案的预计成品备齐日期晚于原交期时，草稿展示延期提醒。用户可通过同一个确认动作保存，服务端仍校验库存、产能、供料和版本，并用订单原交期计算延期风险。修改订单交期仍走订单改期操作。
- 重排只替换草稿列出的有效未开始任务。保存前发现已经开始或有实际，返回具体任务冲突并保护旧版。失效、延期或少产的供料可查询影响任务，真实领用前按现货再次检验。
- 保存失败返回冲突对象和原因，用户可在原草稿继续编辑。重复确认沿用统一事务与幂等机制。见[接口开发规范](系统二-订单与计划-接口开发规范.md)和[数据与事务设计](系统二-订单与计划-数据与事务设计.md)。

## 4. 算例

| 输入 | 应得结果 |
| --- | --- |
| 新加工用杆 10.000 吨，现货 4.000 吨，可按时使用的未来供料 1.500 吨 | 净新增 4.500 吨，铜板计划 4.725 吨。现货、未来供料和新增任务分别列示。 |
| 净新增 1.001 吨，分两天安排 | 铜板总量 1.052 吨，拆到两天的铜板量合计仍为 1.052 吨。 |
| 已认可同一加工范围用杆 10.001 吨，车间二计划 4.000 和 6.000 吨合格产出 | 自动建议用杆 4.000 和 6.001 吨，合计 10.001 吨。用户可调整日份额并重新核对供料。 |
| 原有未来未开始 6 吨，新增 10 吨，连续两天各有 10 吨产能，铜板和用料时间满足 | 联合方案可排首日 10 吨、次日 6 吨，首日 10 吨已含原有 6 吨，库存预留随同一次确认更新。 |
| 车间二要用杆 6 吨，只有同日车间一计划产出 6 吨 | 草稿带先入库后领用约束。车间一未真实入库时车间二仍显示待到料，库存现货尚未增加。 |
