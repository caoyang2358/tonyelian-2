# 系统二 · 生产与能源统计开发指南

本模块提供两个车间的实际产量、电水煤气总量、库存成本和订单估算盈亏。数量来自生产及库存模块，能源来自一期 MySQL 的对应车间计量，金额和价格由其权威入口维护。本文档包用于后续开发，本轮只编写文档，未实现接口或执行数据库迁移。

## 2. 本轮对齐结果

| 事项 | 开发口径 |
| --- | --- |
| 页面入口 | 保留已有「生产与能源统计」侧栏入口。默认当天，同一页展示两个车间。模块内设总量统计、订单核算、库存成本、能源价格四个视图。日分摊和核算进度从来源打开详情。该组织方式是本版页面设计。 |
| 四项总量 | 每车间分别展示电 kWh、水 m³、煤气 Nm³、合格产量吨。车间一铜杆与车间二铜丝分别统计。 |
| 当日记录完整性 | 用户本轮确认新增按车间、实际日的「当日生产记录已录全」。补录或更正使原确认失效，重新确认前仍可查看已知量，相关成本及利润待核算。它与任务结束、订单结束分别保存。 |
| 车间一同日产出 | 用户本轮确认同一次生产的材料金额按各次实际合格铜杆重量分配，当天车间一能源按当天各次合格铜杆重量分配。材料按原始投料 ID 只计一次。 |
| 车间一延后场景 | 跨日尚未产出时的累计成本、整日无生产仅待机的费用归集继续按基线 11.12 延后。保存真实事实，相关成本待核算。 |
| 车间二分摊 | 有产出且当日记录已录全时，按当天各订单与公共部分的实际合格铜丝量分摊全日能源，包含待机消耗。整日零产出须有明确事实依据，能源单列车间。 |
| 计量不足 | 无表计、质量不合格、覆盖不全、未称重、缺价格分别提示。当前开发资料缺车间二独立煤气总表，接入前对应费用和受影响利润待核算。 |
| 成本与利润 | 采用材料与能源简化估算。铜杆随总实物移动加权，公共成品仅自由同规格部分参与均价。取消无利润；减量及不足量结束按人工确认的适用金额。 |
| 价格与修订 | 按实际用能日匹配，优先适用车间专用价，无适用专用价再取通用价。正常新价保留已核定历史，原错误留痕更正并追溯补算。优先级及尾差处理属于统一技术规则。 |

本轮两项新增业务确认写入需求基线和生产记录配套契约。能源范围、单价和金额仍需实际资料。日确认表达录入完整性，不能替代缺失的计量、投料金额或归属明细。

## 3. 开发边界及先后

先打通只读总量与来源质量，接当日录全状态，再接有效价格、日分摊，最后接成本运行、库存价值与订单盈亏。前端可使用明确标注的开发夹具；正式查询按真实接口结果显示。缺来源时交付真实缺项状态，保留后续补齐联调的入口。

业务表复用 V6 的 `p2_energy_price`、`p2_cost_run`、`p2_energy_allocation`、`p2_stock_cost_ledger` 和 `p2_order_cost_item`。日完整性和核算发布所需的新增结构在[数据与计算设计](系统二-生产与能源统计-数据与计算设计.md)中逐项说明，开发时新增 Flyway 迁移，保留 V5、V6 等已发布文件。

原始事实写入、库存数量、分配、交付和订单金额沿用其唯一命令。统计查询仅读取。源数据保存后由后端自动识别受影响核算；手工补算用于补齐和失败恢复，不能成为每笔生产后新增的必点审批。核算补算只处理成本及其结果，不再次产生实物入出库。

## 4. 完成标准

两个车间的真实总量、缺失和已知零可区分；完整日的分摊和金额能守恒；库存在库价值、订单成本和来源份额不重复；补录或更正后重算可追溯，旧结果保留且不误显示为当前最终利润。接口、前后端和隔离 MySQL 的实施验证按验收文档执行，本轮文档检查不代替这些功能验收。
