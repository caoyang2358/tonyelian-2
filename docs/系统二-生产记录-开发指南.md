# 系统二 · 生产记录开发指南

「生产记录」负责把投料、领杆交接、实际起止、称重和生产结束登记成可追溯的事实。每次真实数量保存都通过共享库存服务同步过账，订单、计划和核算读取同一份事实。

## 已确认的页面操作

- 进入模块时显示当天两个车间的生产任务，支持按日期、车间与订单筛选。「实际记录」用于查历史和补录，首页提供「计划外生产」入口。
- 任务详情采用计划摘要和实际记录时间线。车间一登记投料与铜杆称重。车间二登记交出、补录接收与铜丝称重。首次登记实际时可同时填实际开始时间。
- 日任务结束和订单生产结束各有入口。前者保留任务原计划与实际差额，后者分别表达足量结束与不足量结束。
- 本轮统计模块对齐确认增加「当日生产记录已录全」，按车间和实际日核对当天已发生的计划内外事实。S2-R18 查询状态，S2-R19 声明录全。补录或更正使确认失效，跨日更正影响原新两日；相关成本在重新核对前待核算。任务结束、日录全和订单结束各自表达其事实。

## 实施约定

计划内实际沿用「订单与计划」的 `taskId`。已有任务的跨日登记和历史补录仍归原任务，实际日期用于统计。计划外生产的第一笔真实记录通过 S2-R17 建立生产归集，后续事实沿用归集 ID。该设计允许投入、交接和称重分次补齐，并保留各自实际日期。对应存储在实施阶段使用增量 Flyway 迁移。

第一条联调链路从已生效日任务和铜板预留开始，先登记实际投料，再分次称重合格铜杆，逐步核对实物、预留及未来供料。随后接车间二交接、铜丝称重与订单归属，再验证结束、更正及计划外补录。材料金额、归集和来源从第一笔实际起保留，核算待依据齐备后接入。

按车间、实际日确认录全后，[生产与能源统计](系统二-生产与能源统计-开发指南.md)采用同一份有效称重及来源。材料金额、能源计量或单价缺项不阻止真实事实登记与日录全声明，仍会阻止完整成本和利润。铜丝分次称重需保留对应实际领杆来源份额；唯一明确来源可推导，多来源未明确时数量照实保存，相关成本待补，不再扣一次铜杆库存。
