# 系统二 · 生产与能源统计页面与交互规格

## 1. 入口与视图

沿用现有「生产与能源统计」侧栏入口，默认当天。模块内使用「总量统计」「订单核算」「库存成本」「能源价格」四个视图。每日分摊为总量的详情，核算进度为关联详情或侧面板，保持业务上下文。页面沿用项目的布局、表格、筛选与表单样式。

| 视图 | 筛选与主要内容 | 进入详情 |
| --- | --- | --- |
| 总量统计 | 实际日期范围，默认当天；车间默认全部。两个车间上下展示，每车间四项总量，再列每日数据。来源 S2-E01/E02。 | 点击车间某日查看当日来源与分摊 S2-E03。 |
| 订单核算 | 订单、规格、生产结果、核算状态，默认展示可查询的订单，服务端分页。来源 S2-K03。 | 点击订单打开 S2-K04，查看金额、有效成本和缺项。 |
| 库存成本 | 物料、类别、规格，显示铜杆及分规格铜丝。来源 S2-K01。 | 打开成本流水 S2-K02，再定位投料、称重、交接、分配或交付原记录。 |
| 能源价格 | 能源类型、通用或车间范围、生效日，默认当前价格，支持查看修订历史。来源 S2-E04。 | 新增价格 S2-E05；从原价格进入留痕更正 S2-E06。 |

四项总量分别为用电 kWh、用水 m³、煤气 Nm³、合格产量吨。车间一标题标明「合格铜杆」，车间二标明「合格铜丝」，不展示两阶段产量相加的全厂产量。不同能源种类分别显示数值与单位。

日期筛选以实际生产或用能日为准，页内同时展示筛选范围。补录日和录入时间仅在来源详情标注。区间汇总来自服务端全范围，切换分页不改变汇总。变更筛选时取消或隔离旧请求，旧车间、日期、订单的结果不能回填当前视图。

## 2. 总量与完整性

| 状态 | 页面显示 |
| --- | --- |
| 完整 | 展示完整数值和单位，允许明确的零。可展开来源车间总表、覆盖日期、质量与最后刷新时间。 |
| 部分已知 | 展示「已知 ××，数据未齐」，列出缺失日期、表计、质量或未录全生产日。完整总值保留为空。 |
| 无可用来源 | 展示「暂无有效计量」或「待录入称重」及具体缺项。数值使用空值占位，不能显示为零。 |
| 明确整日零产出 | 显示「已确认无合格产出」，可查确认范围、原因、人员和日期。能源仍按各自真实计量显示。 |
| 读取失败 | 保留筛选与已展示来源时间，提示重试。旧值带读取时间和非最新提示，不能冒充本次成功结果。 |

每日列表显示实际日、三项消耗、本车间合格量、生产录全状态、计量缺项及核算状态。数据未齐时仍可查看已经取得的来源。开发夹具必须有「模拟数据」标记，正式环境不以夹具补齐缺表计。

## 3. 当日来源与分摊详情

详情顶部固定车间和实际日。展示「当日生产记录已录全」状态、确认人员与时间，以及是否因补录更正失效。S2-R18 返回当前状态，S2-E03 返回相应核算依据。提供「查看/确认当日记录」进入生产记录模块，携带同一车间及实际日，确认操作使用 S2-R19。

日确认前先让用户核对该车间当天计划内、计划外、换单称重及归属明细。确认只声明已有记录录全，不自动称重或把未填量设为零。存在有效待称重或影响分母的未明确依据时显示阻塞项。没有合格产出时提示先通过生产记录确认整日零产出。确认后的历史补录仍能如实保存；回显「原日确认已失效，需要重新核对」。

| 区域 | 内容 |
| --- | --- |
| 计量来源 | 每种能源的车间总表身份、日或小时来源、范围覆盖、原质量、采纳结果、数值和刷新时间。只采纳一套不重叠来源。 |
| 产量依据 | 有效称重记录、产品规格、计划内或计划外、任务及订单份额、公共部分、合格总量和录全状态。原称重只合计一次。 |
| 适用价格 | 每类能源的范围、生效日、单价及单位、价格版本、采用快照，可进入价格原记录。 |
| 分摊明细 | 车间二展示订单及公共份额、实际量、分母、比例、各项分摊消耗与费用。车间一展示归入铜杆的各次产出份额及材料来源。 |
| 校验及追溯 | 展示各项分摊合计与源总量、总费用，核算运行、规则版本、缺项及原新结果的关联。 |

车间二说明文案为「按当天实际合格铜丝重量分摊全日消耗，含待机消耗，属于经营估算」。公共部分单独成行。完整无产出日的能源列在车间费用中。未录全或缺能源时显示待分摊依据，保留已知量。

车间一同次生产材料按实际合格铜杆重量分配，当天能源按当天各次合格铜杆重量分配。同一次投料被分次称重引用时只归集一次材料成本。跨日未产出累计成本、整日无生产待机费用显示本版待核算说明及来源事实。

## 4. 订单核算与来源补齐

订单列表分别显示生产结果、交付结果和核算状态，列出适用约定金额及是否确认、已核算成本、完整总成本、估算盈亏、待补项数量。金额未齐时保留已知部分。订单生产中显示核算中，阶段性金额差额不显示成最终利润。

详情顶部标注「材料与能源简化估算」，成本分为有效计入项和来源展开。铜杆带入成本内含铜板及车间一能源，展开说明时标注已包含的金额。公共成品带入成本同理，不能将来源展开行再次合计。支持按来源跳转到原任务、计划外归集、投料、称重、交接、库存流水、成品归属、交付及价格记录。

| 情形 | 显示及下一步 |
| --- | --- |
| 新生产正常结束、金额和成本齐全 | 展示适用金额减完整成本的估算盈亏，保留核算时间和版本。 |
| 全部使用既有成品 | 显示「无需生产」，按已确认成品归属和成本核算。缺归属时打开订单与计划办理。 |
| 不足量结束 | 并列原要求、实际、差额及原因，按人工确认的实际约定金额核算。金额待确认时提供订单详情入口。 |
| 减量后 | 并列当前数量与适用金额是否确认。金额可与原金额相同，确认由订单模块完成。 |
| 取消 | 保留历史成本、已交付及转公共依据，盈亏显示不适用。 |
| 日确认失效或来源变化 | 标明核算待更新。旧版本在历史中可查，当前最终盈亏为空。 |
| 缺材料金额、期初成本、表计或价格 | 列出具体来源、日期、字段与补齐入口。缺表计指向接入说明，不能要求用户填一个虚构费用。 |

来源补齐后原命令自动触发核算。页面按返回运行 ID 查看进度。仅在需要受控补算或失败恢复时提供「重新核算」，展示将检查的来源及范围，并要求经办人和原因；实际影响范围由后端返回。页面不开放任意修改成本、均价或利润的输入框。

## 5. 库存成本

铜杆显示全部实物吨数、有效预留、在库成本与均价。预留部分保留在均价分母中。成本缺失时可显示真实数量，均价和总价值按完整性显示已知或待核算。

铜丝按规格显示总在库、已归属订单、自由公共部分及相应价值。公共均价说明为「仅未分配的同规格公共库存」。库存正式分配给订单时，公共份额和价值转入订单归属，总实物及总在库价值保持；交付才减少总实物与对应价值。取消、减量和释放回公共保留原成本，显示来源。

流水列出实际日、录入或更正时间、事件、数量依据、金额影响、均价、来源和核算版本。归属转移与实物出入库分别标注。每次查询固定一个发布版本，历史版本独立查看，不把多个运行的投影累加。

## 6. 价格维护

新增表单包含能源、通用或指定车间、生效日、单价、经办人，单位随能源固定展示。单价允许明确零，负数和超精度定位报错。同范围同能源同生效日重复时提示打开原价格核对。

新增普通生效价的说明为「按实际用能日生效；已核定历史保留原价格依据」。原错误使用「更正原价格」，并列原新值、填写原因，保存后展示受影响范围和核算进度。更正不能删除原始价格历史。

## 7. 运行、冲突与错误

- `PENDING/RUNNING` 显示等待或计算中，保留可查询的已发布版本及其时间。`INCOMPLETE` 显示具体缺项，`FAILED` 显示安全错误和可用的重试动作。新来源已经变动时，旧结果仅作历史参考。
- 成功后刷新当前上下文。409 保留表单输入及筛选，展示版本变化或影响范围，用户核对最新来源后再提交。修改内容使用新请求 ID，原样重试沿用原 ID。
- 400/422 定位非法日期、单位、精度或缺少的依据。网络不确定时先查询已有运行，再按原请求重试，防止重复创建价格或核算。
- 核算轮询只针对当前打开的运行，切换详情或离开页面时停止旧轮询。运行完成后仅读取当前筛选结果，不回填已切换的订单和日期。
